REDoc Bridge Hi 文档 → 企业微信文档
纯前端 · 零服务器 · 数据不上传
01 · 这是什么
把 Hi 文档无损搬进企微
直接复制粘贴，表格会炸、合并单元格没了、高亮块消失……
这个工具解决这件事。复制 REDoc 内容粘贴进来，3 秒转换，再粘贴到企微文档。
表格 + 合并单元格
列宽自动分配
高亮块（7种颜色）
引用块
分栏布局
标题层级（目录可识别）
笔记卡片链接
字体颜色 / 加粗 / 斜体
图片（可调宽度）
有序 / 无序列表
荧光背景色（企微硬限制）
Checkbox（企微不支持）
02 · 开始转换
粘贴 REDoc 内容
在 Hi 文档页面 Ctrl+A 全选 → Ctrl+C 复制，然后粘贴到下方：
1
粘贴内容
2
点击转换
3
复制 → 粘贴企微
在这里粘贴（Ctrl+V / ⌘V）...
⚠️ 粘贴到企微文档时，如弹出 「检测到 Markdown 语法，是否转换」——请点 「取消」或「否」，否则格式会错乱。
✅ 转换完成，点右侧按钮复制
图片宽度 400px
03 · 使用说明
三步完成迁移
①
在 Hi 文档里复制
打开要迁移的 Hi 文档 → Ctrl+A 全选（或 ⌘A）→ Ctrl+C 复制（或 ⌘C）
②
粘贴到这里，点转换
在上方粘贴框 Ctrl+V → 点「转换」→ 点「复制富文本」
③
粘贴到企微文档
打开企微文档 → Ctrl+V 粘贴 → 弹出 Markdown 提示点「取消」即可
